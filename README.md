# Vedant's Portfolio

Live at → **[vedantmh48-cpu.github.io/portfolio](https://vedantmh48-cpu.github.io/portfolio/)**

A personal portfolio built with React + Vite, featuring smooth GSAP animations, a custom cursor, ambient background, and a preloader.

## Stack

- React 18
- Vite
- GSAP (ScrollTrigger)
- React Router DOM
- React Icons

## Sections

- Hero
- About
- Projects
- Clients
- Skills
- Contact

## Run Locally

```bash
cd portfolio-standalone
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Deploys to the `gh-pages` branch → served at `vedantmh48-cpu.github.io/portfolio`.
