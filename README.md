## ✨ Key Features

* **⚡ Lightning Fast:** Powered by Vite & React 18 for high performance and smooth renders.
* **🎭 Dynamic Motion:** GSAP & `ScrollTrigger` driving fluidity across sections.
* **🖱️ Custom Experience:** Features an interactive custom cursor, animated ambient background, and smooth preloader sequence.
* **📱 Fully Responsive:** Clean layout tailored across desktop, tablet, and mobile displays.

## 🚀 Getting Started

Quickly setup and run the portfolio locally on your machine.

### 📋 Prerequisites

Make sure you have **Node.js** (v18 or higher recommended) installed:

[![Node.js](https://img.shields.io/badge/Node.js-339933?style=for-the-badge&logo=nodedotjs&logoColor=white)](https://nodejs.org/)
[![npm](https://img.shields.io/badge/npm-CB3837?style=for-the-badge&logo=npm&logoColor=white)](https://www.npmjs.com/)

---

### 💻 Local Setup

Run the following commands in your terminal:

```bash
# 1️⃣ Clone the repository
git clone [https://github.com/vedantmh48-cpu/portfolio.git](https://github.com/vedantmh48-cpu/portfolio.git)

# 2️⃣ Navigate into the project folder
cd portfolio-standalone

# 3️⃣ Install project dependencies
npm install

# 4️⃣ Launch local development server
npm run dev
```
Note: The dev server will typically spin up at http://localhost:5173.
